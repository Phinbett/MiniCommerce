# MiniCommerce

## Overview

MiniCommerce is a custom Microsoft Dynamics 365 Business Central extension for learning and demonstrating practical AL development through a small commerce-management application.

## Objectives

- Model commerce master data.
- Build customer, product, supplier, and category pages.
- Implement sales orders and sales lines.
- Apply AL validation, record handling, and business logic.
- Use events and subscribers to support extensible behavior.
- Maintain source control and project documentation.
- Explore AI-assisted sales analysis in a later phase.

## Initial Scope

- Customers
- Products
- Suppliers
- Product categories
- Sales orders and sales lines
- Management codeunits and event subscribers

## Technology

- Microsoft Dynamics 365 Business Central
- AL language
- Visual Studio Code
- Git and GitHub

## Development Approach

Features will be built incrementally. Each stage will include AL implementation, validation, testing, and documentation.

## Status

Initial development: master-data foundation and project architecture.
